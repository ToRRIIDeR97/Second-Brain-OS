# Fixture catalogue

Fixtures are small, deterministic, and safe to copy into temporary directories.
Generated large trees are created by scripts rather than committed.

| Fixture | Purpose |
|---|---|
| `workspace-small/` | Ordinary Markdown and source files |
| `workspace-malicious/` | Traversal, secret-like, and active-content inputs |
| `markdown/` | Golden Markdown codec round trips |
| `viewers/` | File routing and bounded preview inputs |
