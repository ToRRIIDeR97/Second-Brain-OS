# Second Brain OS cleanup — 2026-09-26

The active product is the Electron/Solid application in `opencode/`: local
files, knowledge, projects, planning, and agent work. This cleanup removes
unrelated upstream products and retires the unused root Tauri application.
It does not claim that every planned Second Brain feature is implemented.

## Removed

- Hosted console/billing, public websites and documentation sites, statistics
  services, enterprise sharing service, cloud functions, Slack/GitHub bots,
  VS Code extension, identity assets, and container recipes.
- Their SST infrastructure, generated environment stubs, upstream workflows,
  release/changelog automation, promotional translations, and old QA artifacts.
- The standalone upstream installer, npm publisher scripts, and Nix distribution
  graph. These were not used by the active Electron build.
- Root React/Tauri donor source, the Rust MCP executable, Cargo/Rust/pnpm
  manifests and locks, and donor release scripts. Four donor SQL schemas are
  preserved in `archive/tauri/migrations/` for future data-import work.

This removes 1,897 tracked upstream/donor files. The desktop SQLite test was
also renamed to run under Node rather than Bun. Untracked build caches and
local user files were left alone, including the pre-existing `.gitignore` edits.

## Retained deliberately

- Electron host, Solid renderer, managed server, agent providers and tools,
  permissions, MCP support, terminal, file operations, session history, and
  workspace routing.
- Both current runtime generations and their database migrations. Current
  desktop startup and persisted sessions still depend on compatibility paths.
- The workspace manager, old encoded-directory session links, settings
  migration, and supporting layout adapters. Removing them wholesale would
  affect existing session navigation. Shared UI components and language/tool
  support remain available for arbitrary project files.
- Product/security contracts, test fixtures, implementation records, and
  handovers. Historical Tauri documents are requirements/history, not evidence
  that their controls run in Electron.

## Product and tooling changes

Brain home now owns `/`; `/brain` redirects there. The workspace manager remains
at `/workspaces`, reached by Open Workspace actions. Sidebar Home returns to
Brain home. Focused browser tests cover these routes and the workspace picker.

Root commands and GitHub workflows now check/build the active Electron product.
The Bun workspace and lockfile no longer include removed products. The renderer
explicitly references Vite's client types instead of obtaining them indirectly
from removed dependencies.

Display names and installer filenames use Second Brain OS. Existing application
IDs, user-data locations, and URL schemes are preserved. Automatic updates and
publishing are disabled; the manual release workflow uploads an unsigned
Windows candidate and checksums as workflow artifacts only.

Three existing test problems were corrected: Bun cannot run the desktop's
`node:sqlite` test, Windows `echo` quotes differ, and the event manifest had gained
two harness events without updating its server test. CLI subprocess tests now
use the current Bun executable's absolute path instead of relying on PATH lookup.
